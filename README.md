`main.py` (Python standard library only) writes one original
fortune-cookie line for a houseplant to `/output/entry.txt`:

> You will outgrow this pot by spring, and find richer soil, a sunnier
> sill, and a keeper who finally waters on time.

Run it with:

```sh
python3 main.py
```

It self-checks that the line is a single line of 1 to 120 characters
before writing it.
